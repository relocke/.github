# Support

Use the issue tracker in the relevant repository for reproducible bugs, documentation problems, and focused feature requests.

Before opening an issue:

1. Remove credentials, private keys, tokens, personal data, and proprietary project content.
2. Search for an existing report.
3. Include the affected version, environment, expected behavior, actual behavior, and minimal reproduction.

Please do not use public support channels for security vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead.
